# Imágenes pendientes

Las 309 imágenes de nodo de la ruta original (hasta Nimrodel y el antiguo final de Lothlórien) están todas; faltan las 198 del Camino a Mordor (sección siguiente). Las 22 de la tabla final se generaron el 2026-10-13 por código (`tools/node-images/`, Python + Pillow + NumPy) imitando el estilo de las originales: pixel-art de 256×192 escalado ×4 a 1024×768, paleta de 32 colores, tramado ordenado y el viajero con capucha roja. Están en `imagenes/<zona>/` y en `app/src/main/res/drawable-nodpi/`.

El 2026-10-13 y el 2026-10-14 se sustituyeron 101 imágenes (bree, chet, cima y moscagua completas y 13 de puente) por las generadas con Gemini a partir de `prompts-imagenes-pixelart.md` (originales en `docs/content/gemini/`, convertidas con `python tools/gemini/generate_images.py convert`, que recorta a 4:3 y guarda WebP 1024×768). Para añadir más: deja `<clave>.png|jpg|jfif|webp` en `docs/content/gemini/` y vuelve a lanzar `convert`.

Para sustituir alguna por una versión mejor basta con sobrescribir `<clave>.webp` en ambas carpetas (WebP 1024×768). Para regenerarlas: `cd tools/node-images && python run.py <carpeta_salida> [claves...]` (deja también una hoja de contactos `_sheet.png`).
