# Combat v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the combo system with the tier/chain system of the Combat v2 spec, update the rival bestiary, adapt the app minimally, and re-balance to the "Exigente" targets.

**Architecture:** Same immutable `CombatState` + `reduce`. New data model: `ComboDefinition(family, tier, cost, target, effect: ComboEffect)` with a sealed `ComboEffect`; `Fighter.chain: ComboChain`; `ActiveEffect.sourceCombo` identifies effects; `ComboTuning` holds the base percents. `ComboApplier` and `TickResolver` are rewritten around the spec §4–§7 rules.

**Tech Stack:** Kotlin 2.4.20, JUnit5/kotlin.test (`:engine`, `:sim`), Compose + Robolectric (`:app`).

**Spec:** `docs/superpowers/specs/2026-10-12-combat-v2-design.md` (supersedes combat spec §3.3, §3.4, §4, §5.1; the content spec §3 bestiary is rewritten in Task 2).

## Global Constraints

- `:engine` stays pure/deterministic; only external dep `kotlinx-serialization-json`. All numbers Int; percents as Int.
- Invalid actions never throw. Exhaustive `when` over sealed types/enums, no `else`.
- No git. Gradle with `JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"`.
- **Transitional build ruling:** Task 1 changes the engine API, so `:sim` and `:app` (and the content tests `RealContentTest`/bestiary tests) are expected to be red until Tasks 2–4 adapt them. Each task's verification lists exactly which modules/tests must be green. After Task 4 everything is green with zero `w:` lines.
- UI strings in Spanish; code in English.

## Review Focus

1. Chain edge cases: a rejected combo (no power / dazed) must not touch the chain; a non-tier combo (11, 2132, 123) breaks it; tier-4 repeat after a full chain keeps the bonus. (Task 1)
2. Effect identity `(target, sourceId, sourceCombo)`: recasting refreshes, never duplicates; `12` and `13` stack. (Task 1)
3. Daze roll RNG order is deterministic (fighters by index, draw only when chance > 0). (Task 1)
4. Drain pulses exactly 6 times at c+5…c+30 and never heals above max HP. (Task 1)
5. Every rival pattern in content uses only v2 combos; validator rejects removed sequences (e.g. "23"). (Task 2)

- `data class ComboDefinition(val sequence: String, val name: String, val family: ComboFamily, val tier: Int, val cost: Int, val target: TargetKind, val effect: ComboEffect, val baseTicks: Int, val chainBonusTicks: Int = 0)`
- `object Combos { val all: List<ComboDefinition> /* 28, spec §3 */; fun find(sequence: String): ComboDefinition?; const val DOT_TICKS = 10; const val DAZED_TICKS = 10; const val DRAIN_TICKS = 30; const val DRAIN_PERIOD = 5; const val DAZE_CAP_PCT = 55 }`

- `data class ComboChain(val family: ComboFamily? = null, val tier: Int = 0)`; `Fighter.chain: ComboChain = ComboChain()`; `object ChainRules { fun next(chain: ComboChain, combo: ComboDefinition): Pair<ComboChain, Boolean /* chained */> }` per spec §4.
